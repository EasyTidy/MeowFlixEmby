## 2. 已完成明细

### M0 脚手架 ✅
- Go module + 标准分层目录（`cmd/` `internal/` `pkg/`）。
- `internal/config`：YAML 加载 + 校验 + 环境变量覆盖（`MEOWFLIX_SERVER_*`）。
- `pkg/*` 核心 interface 定义：mediaserver / resolver / player / remote。
- `cmd/meowflix/main.go`：`-config` 参数、`context` 生命周期、信号优雅退出、`log/slog`。
- `configs/meowflix.example.yaml`、`.golangci.yml`、`.gitignore`、`README.md`。

### M1 决策引擎 ✅（纯逻辑，表驱动单测）
- `pkg/resolver/engine.go`：4 级优先决策 —
  1. `force_disk_prefixes` → DirectDisk
  2. HTTP 源 + `direct_url_hosts` 命中 → DirectURL
  3. `path_maps` 可翻译（挂载 NAS）→ DirectDisk
  4. 兜底 → HTTPStream
- `pkg/resolver/pathmap.go`：src→dst 前缀替换、分隔符归一、可选 NFC/NFD 路径校验。
- `pkg/resolver/version.go`：多版本按关键词优先级选源。
- `pkg/resolver/subtitle.go`：外挂/内嵌字幕选择。
- 测试：`engine_test.go`、`helpers_test.go` 覆盖 4 条决策路径 + 边界。

### M2 服务器适配（Emby REST）✅
- `pkg/mediaserver/emby/client.go`：`X-Emby-Authorization` / `Authorization` / `X-Emby-Token` 头；Emby(`Emby`)/Jellyfin(`MediaBrowser`) 双认证 scheme；`doJSON` 助手。
- `pkg/mediaserver/emby/server.go`：实现 `mediaserver.Server` —
  认证（`POST /Users/AuthenticateByName`）、能力声明（`/Sessions/Capabilities/Full`）、
  `ResolveItem`（PlaybackInfo/MediaSources）、`StreamURL`、`SubtitleURL`、
  进度回传（`/Sessions/Playing[/Progress|/Stopped]`）。
- `pkg/mediaserver/emby/dto.go`：JSON DTO + `toDomain()`。
- 测试：`server_test.go` 用 httptest 验证认证头、能力、解析、进度 payload、错误传播、Jellyfin scheme。
- 约定：`PositionTicks = 秒 × 10,000,000`（100ns tick）。

## 3. 待办明细

### M3 遥控会话（WebSocket）⏳
- 连接 `/embywebsocket?api_key=&deviceId=`（Jellyfin 路径 `/socket` **[待联调核实]**）。
- 保活心跳、断线重连、重发 Capabilities。
- 收 `Play` / `Playstate` / `GeneralCommand` 指令并分发。
- **可离线先做**：`pkg/remote` 消息编解码 + 单测。
- **需真实环境**：本机出现在"Play On"、实际收指令。

### M4 播放器驱动 ⏳
- mpv（JSON IPC，一等公民）优先，其次 vlc / potplayer / generic。
- 起播、暂停/快进/停止、进度读取。
- **可离线先做**：mpv IPC 协议编解码 + 单测。
- **需真实环境**：真实播放器起播与遥控生效。

### M5 编排闭环 ⏳
- `pkg/playback` controller 串联：投放指令 → resolver 决策 → 播放器起播 → 进度回传 → 连播。
- `internal/app` 装配全链路。
- 依赖 M3 + M4。

### M6 跨平台与集成 ⏳
- `scripts/build.sh`：`GOOS/GOARCH` 交叉编译 win/mac/linux 单文件。
- 自启模板：Windows 计划任务、macOS launchd、Linux systemd user unit。
- `c-shared` FFI 导出（`.dll/.so/.dylib` + 头文件）+ 调用示例。
