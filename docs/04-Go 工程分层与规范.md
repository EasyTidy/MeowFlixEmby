# MeowFlixEmby — Go 工程分层与规范

> 第 4 部分。上一篇：[03-架构设计.md](03-架构设计.md)；下一篇：[05-实施计划.md](05-实施计划.md)

## 1. 遵循的规范来源

| 规范 | 用途 |
|------|------|
| [Standard Go Project Layout](https://github.com/golang-standards/project-layout) | 目录分层：`cmd/ internal/ pkg/` |
| [Effective Go](https://go.dev/doc/effective_go) | 语言惯用法 |
| [Google Go Style Guide](https://google.github.io/styleguide/go/) | 命名、格式、接口 |
| [Go Code Review Comments](https://go.dev/wiki/CodeReviewComments) | 评审惯例 |
| SemVer 2.0 / Conventional Commits | 版本与提交 |

核心原则：**面向接口编程 + 依赖注入**，让"媒体服务器""播放器""播放方式决策"三大领域都可被第三方替换实现——这是"可插拔"的工程落点。

### 分层依赖方向（严格单向）

```
cmd/ ─► internal/app ─► pkg/*     （app 负责把各 pkg 组装起来）
pkg/playback ─► pkg/{mediaserver, resolver, player, progress, remote}
pkg/* 之间只依赖对方的 interface，不依赖具体实现
internal/ 不被 pkg/ 依赖（pkg 要能被外部独立复用）
```

## 3. 核心接口（可插拔契约草案）

```go
// pkg/mediaserver/mediaserver.go
type Server interface {
    Authenticate(ctx context.Context) error
    // 打开遥控会话：注册能力 + 返回指令流
    OpenSession(ctx context.Context, caps Capabilities) (<-chan RemoteCommand, error)
    // 拿到媒体的播放信息（含服务器端文件路径、直连流、strm 源、字幕、多版本）
    ResolveItem(ctx context.Context, itemID string) (*MediaItem, error)
    // 进度回传
    ReportStart(ctx context.Context, p PlaybackState) error
    ReportProgress(ctx context.Context, p PlaybackState) error
    ReportStopped(ctx context.Context, p PlaybackState) error
}

// pkg/resolver/resolver.go
type Method int
const (
    MethodDirectDisk Method = iota // 本地磁盘路径（NAS 已挂载）
    MethodDirectURL                // 直连网盘 URL（strm/http 源）
    MethodHTTPStream               // Emby HTTP Direct Stream
)
type Resolver interface {
    // 依据 MediaItem + 本地配置，选出最佳播放方式与最终 media path/url
    Resolve(item *mediaserver.MediaItem, cfg Config) (Decision, error)
}

// pkg/player/player.go
type Player interface {
    Name() string
    Start(ctx context.Context, req PlayRequest) (Handle, error)
}
type Handle interface {
    // 进度、时长（供回传与连播判定）
    Progress() (posSec, durSec float64, ok bool)
    // 遥控：暂停/继续/跳转/停止/切集
    Control(cmd ControlCmd) error
    Wait() (stopSec float64, err error) // 阻塞至退出
}
```

## 4. 工程规范细则

- **错误处理**：返回 `error` 并用 `fmt.Errorf("...: %w", err)` 包裹；不 `panic`（除 `main` 装配期不可恢复错误）。
- **上下文**：所有网络/子进程/IPC 调用首参 `ctx context.Context`；守护进程用可取消的根 ctx，收到信号优雅退出。
- **并发**：goroutine 必须有明确退出路径（`ctx.Done()` 或 channel 关闭）；共享状态用 channel 或 `sync` 原语，`go test -race` 必过。
- **日志**：`log/slog`，结构化字段；支持等级；默认脱敏 token/域名（对齐参考项目 `mix_log`）。
- **配置**：YAML 为主（比参考项目的 ini 更表达力强），支持环境变量覆盖；启动时校验并给出可读报错。
- **测试**：决策引擎（`resolver`）、路径转换、版本/字幕优选必须有单元测试（表驱动）；媒体服务器与播放器用接口 + mock。
- **Lint**：`golangci-lint`（govet、staticcheck、errcheck、revive 等）。
- **命名**：包名短小全小写无下划线；导出标识符首字母大写并写 doc comment；接口用 `-er` 或领域名。
- **版本/提交**：SemVer 管理 `pkg/` 对外 API；Conventional Commits。

## 5. 配置模型（YAML 草案）

```yaml
server:
  type: emby                     # emby | jellyfin | plex
  address: https://emby.example.com
  username: alice
  password: ""                   # 或使用 api_key
  api_key: ""
  device_name: "MeowFlix (Living Room PC)"

playback:
  # 服务器端路径前缀 → 本地磁盘前缀（NAS 挂载）
  path_maps:
    - src: /mnt/disk1
      dst: E:\
    - src: /mnt/disk2/media
      dst: F:\media
  # 命中这些前缀强制走本地磁盘
  force_disk_prefixes: []
  # 命中这些域名/关键字的 strm/http 源，直连 URL
  direct_url_hosts: []
  path_check: false              # 转换后校验文件存在 + NFC/NFD

players:
  default: mpv
  by_path:                       # 按路径关键字选播放器
    - player: vlc
      match: [".iso", "__bdmv"]
  exe:
    mpv: C:\Green\mpv\mpv.exe
    potplayer: C:\Program Files\DAUM\PotPlayer\PotPlayerMini64.exe
    vlc: C:\Green\vlc\vlc.exe

subtitle:
  priority: ["中英", "简", "chi", "ass", "srt"]
version:
  prefer: ["remux", "2160", "1080"]

log:
  level: info
  file: ./meowflix.log
  mask_sensitive: true
```
